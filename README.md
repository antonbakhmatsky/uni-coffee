# UniCoffee demo

Одностраничный сайт-концепт UniCoffee для университетского проекта. Форма заказа работает в демонстрационном режиме: заказ не отправляется в кофейню, оплата не списывается.

Открыть демо: https://raw.githack.com/antonbakhmatsky/uni-coffee/main/index.html

Публикация GitHub Pages также подготовлена в `.github/workflows/pages.yml`; для её включения нужно выбрать GitHub Actions в Settings → Pages.
